# Security

Tracking uses random bearer links and serves a narrow status projection. Private pages discourage indexing and send a no-referrer policy. Checkout validates and reprices on the server. Staff pages and mutations require signed, expiring, HttpOnly SameSite cookies. Local default credentials are public demo credentials. No live payments or external notifications run.

Before public release add individual Better Auth accounts, server-enforced roles, abuse controls and rate limits for authentication and ordering, staff and payment audit, data retention and deletion workflows, and review handling of Quebec privacy and Canadian anti-spam obligations. The platform has not undergone legal or security review.
