# Technology stack

Next.js App Router, React, strict TypeScript, Tailwind CSS, Zod, PGlite and pg provide the first vertical slice. Vitest runs domain and SQL tests. Better Auth handles PostgreSQL-backed staff sessions. Playwright Core drives Chromium browser smoke tests. Node.js 24 is the current development runtime. Exact package versions are pinned in [package.json](../package.json) and integrity metadata is in [package-lock.json](../package-lock.json). Prisma, Stripe, Resend and Twilio remain planned. Avoid splitting the product across deployables while one Next process and PostgreSQL support the workflow.
