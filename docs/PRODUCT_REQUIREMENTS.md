# Product requirements

| Role | Salut Plus journey | Acceptance |
| --- | --- | --- |
| Guest | French or English menu, customize, reserve pickup, pay on site or online | Server quotes supported options, accepts one order per submission, provides a private tracking link |
| Customer | Accounts, history, favorites, reorder, loyalty QR | Only the account holder can see history and points. Reordering revalidates the current menu |
| Staff | Live orders, preparation, pickup payment, QR scans | Updates persist and reach both staff and tracking screens. Sensitive redemptions require fresh authorization |
| Admin | Catalog, promotions, hours, capacity, accounts, notifications, website analytics | Server-enforced roles, auditable changes and consent-aware analytics |
| Owner | Bilingual public website, local discovery, store information | Responsive layout and verified content with official links |

French Canadian defaults, English Canadian is selectable, prices use CAD and pickup uses Toronto time. Transactions protect payments and loyalty. The pilot uses sample products, temporary artwork and rolling slots. Owner decisions include official brand assets, hours, capacity, menu, taxes, location, contact channels, reward rules and retention. See implementation status for delivery state.

Use **Récompenses Salut** in French and **Salut Rewards** in English whenever displaying the full loyalty program name.
